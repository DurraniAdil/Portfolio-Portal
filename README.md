# Portfolio Portal

A gateway to experience my portfolio in the format best suited to your device.

## Overview

I built this portal to guide you toward the portfolio experience that works best for your screen. Rather than forcing a single responsive design, I created two purpose-built versions for different platforms.

## Portfolio Versions

### OS Portfolio (Desktop)

I designed this as a fully immersive operating system simulation featuring windows, taskbars, and multitasking. If you're on a laptop or desktop and want the complete experience, this is for you.

- **Live Demo**: [durraniadil.github.io/Portfolio-OS](https://durraniadil.github.io/Portfolio-OS/)
- **Repository**: [github.com/DurraniAdil/Portfolio-OS](https://github.com/DurraniAdil/Portfolio-OS)

---

### App Portfolio (Mobile)

I built this as a streamlined, social-feed inspired interface optimized for rapid browsing. If you're on a phone or tablet and want to quickly scan through my projects, this is the way to go.

- **Live Demo**: [durraniadil.github.io/Portfolio-App](https://durraniadil.github.io/Portfolio-App/)
- **Repository**: [github.com/DurraniAdil/Portfolio-App](https://github.com/DurraniAdil/Portfolio-App)
